# LKZ Site Foundation

Готовый фундамент репозитория под поэтапную разработку презентационного B2B-сайта каталога.

## Что уже заложено
- Next.js App Router + TypeScript
- Tailwind CSS v4
- GitHub Pages preview через GitHub Actions
- токены темы, радиусов, spacing, типографики
- базовые UI-компоненты
- typed content layer
- базовые типы и валидаторы
- placeholder-структура под Header, Footer, Hero, каталог и формы

## Что нужно сделать после распаковки
1. Открыть проект локально.
2. Выполнить `pnpm install`.
3. Это создаст актуальный `pnpm-lock.yaml`.
4. Проверить локально `pnpm dev` и `pnpm build`.
5. После этого можно заменить содержимое репозитория на GitHub и пушить уже рабочую итерацию.

## Шрифты
Шрифтовые файлы в архив не включены.

Под них уже подготовлены папки:
- `src/fonts/druk-wide/`
- `src/fonts/garet/`

После локальной загрузки файлов можно подключить их через `src/lib/fonts.ts`.
В текущем фундаменте шрифты намеренно не активированы, чтобы не блокировать сборку.

## GitHub Pages
В `next.config.ts` уже подготовлен preview-режим под репозиторий `lkz-site`.
Если имя репозитория изменится, обнови константу `repoName`.
